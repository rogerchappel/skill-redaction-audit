# Security Policy

## Reporting a Vulnerability

Please report suspected security issues through GitHub Security Advisories for this repository, or open a private report with enough detail to reproduce the issue.

Do not include live secrets, private workspace paths, or personal data in public issues. If a fixture needs a realistic-looking value, use a deterministic fake value and document why it is safe.

## Supported Versions

Security fixes are handled on the default branch until the project publishes a stable release line.
